This is a research tool, not financial advice. It reports what public SEC filings say and which published Graham and Buffett tests a company meets. It does not tell anyone to buy, sell or hold anything.

How it works

This is a research tool that turns SEC filings into a scorecard for each S&P 500 company, shows its working, and says where it is unsure. It is written for someone who wants to check the method in five minutes.

The process

  1. Scope and sector. A rule-based planner checks that the company is in the S&P 500 list and decides which tests make sense for it. Banks and insurers have no current assets or operating income, so four tests do not apply to them; utilities use Graham's utility variant of the debt test; real estate trusts keep the normal tests with a note.
  2. Numbers from the SEC. The SEC publishes every tagged figure companies report. The tool keeps full-year figures, picks one value per year, adjusts per-share figures for stock splits, and records for each value the filing it came from. A missing figure becomes a data gap with a reason; it is never guessed.
  3. Eleven tests, plain arithmetic. Seven from Benjamin Graham's defensive-investor criteria (size, financial strength, earnings stability, dividend record, earnings growth, and two price tests) and four from Warren Buffett's (return on equity, conservative debt, stable margins, owner earnings). Python code computes them. No model is involved in any number.
  4. Four questions about the annual report. For companies with a full analysis, one agent per question reads the relevant parts of the latest 10-K by searching it, then must cite the exact sentences it relies on. Code, not the model, builds the quote and its position in the filing from sentence pointers, so a quote cannot be paraphrased or invented.
  5. Explain, then check. The Explainer writes one plain line per score using placeholders instead of numbers; code fills the numbers in. The Critic, a second reviewer that is partly code and partly a model, checks the lines, re-opens the filing to verify every quote, scans for advice language, and asks a model whether the evidence supports each verdict. A failed item goes back once for repair; if it still fails it is shown with a warning.
  6. Publish files. Each company becomes one file with its scores, evidence, checks, cost and a trace of every step. This site only displays those files.

Where the agentic behaviour is

Two places use models that decide for themselves what to do next. The qualitative agents choose what to search for in the filing and when they have enough evidence, within a cap of four turns and with a first search decided by code. The Critic's repair path lets a second model call rewrite a rationale or look again for better evidence. Everything else is deterministic code, on purpose: scoring should be reproducible. You can see every hand-off in the Coca-Cola analysis and its step-by-step replay.

What an analysis costs

Measured on the five sample companies: about 10 model calls and 24,000 tokens per company, which would cost about one cent (under $0.01) at paid rates and cost nothing on the free tier used here. Scoring the whole index needs no model and no 10-K download: it took about 35 seconds from cached SEC data, and about five minutes to download it the first time. A full agent analysis of all 500 companies would cost roughly $5 at paid rates.

How it was tested

  • Gold set for the judgement tests. The agents' verdicts on the five sample companies were reviewed by hand against the 10-K; they agree with the reviewer on 19 of 20, and the one difference is over-generous. See the qualitative report.
  • The Critic against known errors. It caught all three disagreements with the gold set and all three faults that were injected on purpose; its repairs fixed five of five findings it flagged. See the Critic report.
  • The whole index. Scores for 498 companies were checked for anomalies (revenue jumps, odd signs, restatements, split adjustments), and the fixes are written up in the universe report. The count of every label is frozen, so a rule change that moves hundreds of results shows up in the tests.
  • Offline tests. Close to 400 automated tests run without a network connection, on recorded SEC data and recorded model responses.

What it gets wrong

  1. The judgement verdicts lean generous. Where the reviewer disagreed with the agent, the agent had been too positive; the Critic catches most but not all of these.
  2. Rationales can say more than the quotes show. The Critic flags it and asks for a rewrite, but it is a language-model check and can miss things.
  3. Some companies do not report what a test needs. The margin test is a data gap for about 115 companies and the owner-earnings test for about 100, mostly because their filings give no usable operating income or capital spending, or cover fewer than ten years. They are shown as gaps, not guessed.
  4. Dividend history is a short window with data quirks. SEC data covers about 15 years, not Graham's 20. A one-off payment or a mis-tagged figure can make a company look like a payer (Alphabet in 2015 is a known case).
  5. Earnings growth depends on a single unusual year. The growth test compares three-year averages ten years apart, so one odd year can flip it.

The full list, with counts, is in the evaluation notes. The valuation tests are not scored yet: they need a share price, and the price feed is waiting on a data licence.

What I would change with a production budget

  • Run the full agent analysis on every company in one batch on the paid tier (about $5) instead of over several days of free quota.
  • License price and analyst data so the two valuation tests and the analyst ranking can be shown.
  • Use a different, stronger model as the Critic from the one that writes the findings, and measure it on a larger gold set.
  • Replace keyword search with hybrid search when a retrieval test set shows it misses passages that matter.
  • Add point-in-time data, so scores show what an investor could have known then, not today's restated figures.
  • Add a live mode that analyses any listed company on request, behind access codes so spend stays capped.
